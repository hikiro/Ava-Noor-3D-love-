# Villa Verse v1.8 — sewn elbow topology study

**State:** functional rig/mesh prototype; **NOT approved** for production character fidelity or physical interaction.

Two existing cast characters (Ava and Noor) now use topology with **16 connected cross-sectional rows around each forearm and elbow** stitched onto the continuous upper-body surface introduced in v1.7. The arm did not become a disconnected floating tube. This preserves the existing 43 bones, 8 face/cloth morph controls, wardrobe colors, dialogue placeholders and the 5.2-second reach animation. Compared with v1.7, ring topology and corrected blended skin weights reduce orientation/compression risk proxies at the held reach pose. This is **procedural retopology, not manually sculpted Blender-quality anatomy**.

## Main files

- `models/ava_ELBOW_RETOPO_v1_8.glb` and `models/noor_ELBOW_RETOPO_v1_8.glb`: rigged glTF 2.0 animated meshes, 43 bones and 8 morph shapes each.
- `models/*_continuous_upperbody_RETOPO_v18.ply`: detached editable mesh exports of the **single** connected upper body (no bones in PLY).
- `models/base/`: frozen v1.5 source arrays, unchanged.
- `source/build_v18.py`: active source; `source/elbow_retopo_v18.py` constructs the sewn ring rows.
- `source/validate_v18.py`: structural/topology/20-sample numerical QC + decoded-video verification.
- `source/probe_elbow_quality_v18.py`: before/after active elbow metrics at six selected times.
- `source/elbow_weight_sweep_v18.py`, `source/seam_blend_experiments_v18.py`, `source/dual_quat_elbow_corrective_v18.py`: measured probes including **rejected approaches**.
- `source/render_motion_v18.py`, `source/render_elbow_comparison_v18.py`, `source/render_qc_sheet_v18.py`: reproducible previews and timeline inspection.
- `godot/`: **untested in Godot** viewer and headless import audit source.
- `qa/ITERATION_LOG.md`, `qa/validation_v18.json`, `qa/ELBOW_BEFORE_AFTER_METRICS.json`, `qa/PORTABLE_REBUILD.json`: test evidence and unresolved defects.
- `archive/v1_7_COMPLETE_HANDOVER.zip`: full prior source/render history (including v1.6 and earlier version archive).

## Rebuild offline

Python dependencies in `requirements.txt` and local FFmpeg:

```bash
python source/build_v18.py
python source/render_motion_v18.py
python source/render_elbow_comparison_v18.py
python source/render_qc_sheet_v18.py
python source/probe_elbow_quality_v18.py
python source/validate_v18.py
```

A clean extraction using only `source/` and `models/base/` generated byte-identical v1.8 GLBs (SHA256 in `qa/PORTABLE_REBUILD.json`). You may use Blender to import `.glb` for manual repair, but Blender was not available to verify this import here.

## Actual Godot validation, **not yet performed**

Godot 4.x editor binary is required. In a shell at the package root:

```bash
godot --headless --editor --path godot --import
godot --headless --path godot --script res://validate_import.gd
```

On success the latter should exit 0 and print `GODOT ENGINE IMPORT CHECK PASS`. Open `godot/project.godot` and play `Main.tscn` to visually check models at normal speed. Use LEFT/RIGHT for camera orbit, SPACE to pause, R to restart. **No engine result is included in this release.** See Godot CLI docs: https://docs.godotengine.org/en/4.5/tutorials/editor/command_line_tutorial.html
